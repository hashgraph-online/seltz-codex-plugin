# Marketplace listing draft

**Display name:** Seltz

**Short description:** Real-time, source-backed web knowledge for Codex.

**Long description:** Use Seltz's official Streamable HTTP MCP server to search the live web for current,
source-backed context. The plugin exposes Seltz's documented `search` tool, requires users to authenticate
with their Seltz API key in Codex, and does not claim that search output is complete, authoritative, or a
substitute for reviewing linked sources.

**Category:** Research

**Website:** <https://seltz.ai>

**Privacy:** <https://seltz.ai/privacy-policy>

**Terms:** <https://seltz.ai/terms>

**MCP endpoint:** <https://mcp.seltz.ai/mcp>

**Default prompts:**

- Search the live web for current, source-backed information about this question.
- Find recent sources on this topic and summarize what they say.
- Fact-check this claim with current web sources and show the supporting links.
